[EN] QUICK START GUIDE
------------------------------------------------------------------------
Thank you for downloading MirDM (Portable Edition)!

1. HOW TO RUN:
   - MirDM is 100% portable: NO installation or administrator setup required!
   - Ensure "MirDM.exe" and "msquic.dll" remain in the same directory.
   - Simply double-click "MirDM.exe" to launch.
   - You can place this folder anywhere: Desktop, Documents, or USB drive.

2. KEY FEATURES:
   - ⚡ HTTP/3 QUIC & HTTP/2 Acceleration: Eliminates TCP Head-of-Line blocking.
   - 🏎️ Dynamic DNS Edge-IP Racing: Automatically races CDN edge IPs for minimum latency.
   - 🔀 Dynamic Splitter & Tail-Latency Stealing: Actively bifurcates lagging chunks
     so idle connections steal work, saturating 100% of bandwidth until the last byte.
   - 💾 Direct IOCP Zero-Fragmentation Disk I/O: Instantly pre-allocates file bounds
     on NTFS/exFAT and writes asynchronously to exact byte offsets without temp files.
   - 📋 Batch Download & Asterisk (*) Wildcard Generator:
     Import lists of URLs or generate numbered sequences (e.g., episode_(*).mp4).
   - 🧹 Safe "Clear List": Clears items and session data WITHOUT deleting your
     physical files on disk.
   - 🎨 Acrylic Fluent Dark UI: Visual Segment Heatmap, real-time speed graph, and
     speedometer gauge.

3. REQUIREMENTS:
   - Windows 10 (Version 1809+) or Windows 11 (64-bit).
   - "msquic.dll" must be kept in the same folder as "MirDM.exe".
